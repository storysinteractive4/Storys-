I Frame Engine

Storys' powerful standalone engine for building interactive and text-based games. Designed so you can create entire worlds without the need for complex coding.

Recommended System

  • OS: Windows 10 / 11 (64-bit)
  • Processor: Any modern CPU
  • RAM: 2 GB
  • Storage: 10 MB available space
  • Graphics: WebView2 compatible

File Details

  • File Name: I-Frame-Engine.exe
  • Size: ~5 MB
  • Type: Executable (.exe)
  • Installation: Portable (Run directly)
